# 🌦️ Projeto Final JS - Dashboard Meteorológico & Utilizador

Este repositório contém o código desenvolvido para o projeto final utilizando JavaScript, HTML e CSS. A aplicação integra várias funcionalidades interativas, incluindo um relógio em tempo real, um sistema de meteorologia dinâmico baseado em coordenadas geográficas, seletor de cidades e opções de personalização visual (modo claro/escuro e autenticação simulada).

## ✨ Funcionalidades

- **Previsão do Tempo Dinâmica**: Consulta de dados meteorológicos em tempo real (temperatura) através da API [Open-Meteo](https://open-meteo.com/).
- **Seletor de Cidades**: Alternância rápida entre diferentes cidades (Lisboa, Porto, Coimbra) atualizando automaticamente as coordenadas e os dados de temperatura.
- **Relógio e Calendario em Tempo Real**: Visualização contínua da data e hora atuais.
- **Alternância de Tema (Dark/Light Mode)**: Botão interativo para mudar o aspeto visual da página.
- **Simulação de Autenticação**: Botões de *Login* e *Logout* interativos.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página.
- **CSS3** (com Flexbox): Estilização e alinhamento responsivo dos componentes da barra de navegação.
- **JavaScript (Vanilla)**: Manipulação do DOM, gestão de eventos (`onchange`, cliques) e pedidos assíncronos (`fetch` API).
